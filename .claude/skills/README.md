# Vendored skills: mattpocock/skills

The `engineering/` and `productivity/` folders here are copied from
[mattpocock/skills](https://github.com/mattpocock/skills) (MIT licensed, see
`LICENSE-mattpocock-skills`), the promoted skill set listed in that repo's
`.claude-plugin/plugin.json`.

These are plain files, not a live plugin subscription: pulling
`mattpocock/skills` again and re-copying is how to pick up upstream changes.

Run `/setup-matt-pocock-skills` once to configure issue tracker, triage
labels, and doc locations for this repo before using the other engineering
skills (e.g. `/code-review`, `/to-spec`, `/implement`).
